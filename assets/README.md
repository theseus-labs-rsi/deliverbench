# DeliverBench presentation assets

These illustrations accompany the [DeliverBench project](https://deliverbench.github.io/):

- `figure-01-motivation.png`: paper Figure 1, from personal assistance to professional project delivery.
- `figure-03-execution.png`: paper Figure 3, continuous execution and delivery evaluation.
- `figure-08-dependencies.png`: paper Figure 8, syndicated loan refinancing and artifact dependencies (Case 01 in this public dataset).
- `logo-folio.svg`: the DeliverBench project mark.

The figures are direct PNG renders of the paper artwork. Their contents are unchanged.
They describe the benchmark and its task structure; they contain no model scores or run traces.
